ESP32 · Sensores

Dashboard climático com DHT11 e OLED

Organização de um projeto IoT compacto usando ESP32 Super Mini, sensor DHT11 e display OLED.

Hardware

O protótipo utiliza ESP32 Super Mini, módulo DHT11 e display OLED SSD1306. O conjunto permite acompanhar temperatura e umidade localmente.

Ambiente de desenvolvimento

O firmware foi desenvolvido no VS Code com PlatformIO. A configuração de pinos fica centralizada no código para facilitar manutenção e evolução.

Próximos testes

Comparar leituras com instrumento de referência, observar estabilidade das medições e registrar comportamento após longos períodos ligado.

Anotação técnica inicial. O conteúdo será ampliado com código, medições, imagens e decisões de implementação à medida que os registros do projeto forem publicados.
